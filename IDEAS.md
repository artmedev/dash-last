## 1. Make the user follow a productivity method, e.g. GTD

Dash should not only store tasks but keep the user inside a working method such as
Getting Things Done (David Allen):

- **Capture**: one inbox for everything (quick add from any page, later from Telegram or voice).
- **Clarify**: the inbox has to be processed to zero; for each item Dash asks "is it actionable?",
  "what is the next action?", "under 2 minutes? do it now".
- **Organize**: projects, next actions, contexts (@home, @computer, @errands), waiting for, someday/maybe.
- **Reflect**: a mandatory weekly review that Dash leads step by step and reminds about until it is done.
- **Engage**: the home screen shows only the next actions for the current context.

The assistant (Claude) can drive the clarify step and the weekly review as a dialogue.
