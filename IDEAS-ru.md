# Идеи

[English version](IDEAS.md)

Идеи для Dash, которые ещё не запланированы. Новые — внизу.

## 1. Заставлять пользователя соблюдать методику продуктивности, например GTD

Dash должен не только хранить дела, но и держать пользователя в рабочей методике, например
Getting Things Done (Дэвид Аллен):

- **Сбор**: одна «входящая» папка для всего (быстрое добавление с любой страницы, позже из Telegram или голосом).
- **Обработка**: входящие нужно разобрать до нуля; по каждому пункту Dash спрашивает «требует ли действия?»,
  «какое следующее действие?», «меньше 2 минут? сделай сейчас».
- **Организация**: проекты, следующие действия, контексты (@дом, @компьютер, @в городе), ожидание, когда-нибудь/может быть.
- **Обзор**: обязательный еженедельный обзор, который Dash проводит по шагам и напоминает, пока он не сделан.
- **Действие**: главный экран показывает только следующие действия для текущего контекста.

Ассистент (Claude) может вести разбор входящих и еженедельный обзор в форме диалога.
